# C.AI Web Enhancer

Бесплатный open-source userscript для Tampermonkey, добавляющий полезные функции в веб-версию Character.AI.

Проект предназначен для того, чтобы сделать веб-версию C.AI удобнее: сохранить старые чаты в локальном архиве, убрать назойливые рекламные элементы и добавить дополнительные инструменты управления интерфейсом.

## Возможности

### 🗂️ Архив чатов без ограничения списка

В Character.AI список недавних чатов ограничен. Когда появляются новые чаты, более старые постепенно исчезают из видимого списка.

C.AI Web Enhancer автоматически сохраняет исчезнувшие из списка чаты в локальный архив и позволяет продолжать обращаться к ним через отдельный раздел архива.

Архив хранится локально в браузере и не является частью официального списка недавних чатов Character.AI.

### 🔄 Обнаружение чатов через сетевые запросы

Скрипт может отслеживать соответствующие `fetch`- и `XMLHttpRequest`-запросы страницы и извлекать из ответов информацию о чатах.

Благодаря этому архив может собирать данные о чатах в фоне, а не только анализировать элементы, которые в данный момент отображаются на странице.

Текущая версия поддерживает несколько форматов ответов API и умеет искать данные о чатах во вложенных структурах.

### 📦 Импорт и экспорт

Архив можно экспортировать в JSON-файл и затем импортировать обратно.

Это позволяет:

* создавать резервные копии;
* переносить архив на другой браузер или компьютер;
* восстанавливать архив после очистки данных браузера;
* вручную переносить архив между установками userscript.

### 🛡️ Встроенная блокировка рекламы

В скрипте предусмотрен дополнительный режим блокировки рекламных и рекламно-промо элементов Character.AI.

Он использует точечные селекторы и старается не затрагивать остальной интерфейс страницы.

### 🎨 Визуальное отображение состояния чатов

Дополнительный визуальный режим позволяет различать состояние чатов в основном списке и архиве.

Для разных состояний используются отдельные визуальные обозначения.

### 🧪 Режим разработчика и отладка

В скрипте есть инструменты для разработчика и отладки, которые помогают отслеживать работу архива и внутренние действия userscript.

Встроенная консоль может отображать события в фоне и сетевые операции без необходимости постоянно открывать DevTools браузера.

### 🔒 Защита от рассинхронизации вкладок

Скрипт отслеживает устаревшие вкладки и может временно блокировать операции записи в архив, если обнаружено состояние, которое требует перезагрузки страницы.

Это помогает снизить вероятность повреждения или рассинхронизации архива при одновременном использовании нескольких вкладок Character.AI.

## Установка

### 1. Установите Tampermonkey

Установите расширение Tampermonkey для вашего браузера.

### 2. Установите C.AI Web Enhancer

Откройте последний файл `.user.js` из этого репозитория.

Tampermonkey должен распознать его как userscript и предложить установить его.

Также можно открыть исходный файл через **Raw** и установить его напрямую.

### 3. Откройте Character.AI

Перейдите на:

`https://character.ai/`

Userscript запустится автоматически.

## Обновление

Tampermonkey может автоматически проверять наличие новых версий, если в шапке userscript указаны ссылки `@updateURL` и `@downloadURL`.

Для стабильной работы рекомендуется использовать последнюю версию из этого репозитория.

## Данные и конфиденциальность

C.AI Web Enhancer не требует отдельной учётной записи, собственного сервера или внешней базы данных.

Данные архива сохраняются локально в браузере с использованием `localStorage`.

Скрипт обрабатывает доступные странице данные Character.AI для создания и поддержания локального архива.

Проект не предназначен для отправки архивированных данных на внешний сервер.

## Важные замечания

Это неофициальный сторонний userscript.

Проект не связан с Character.AI, не является его официальным расширением и не поддерживается Character.AI.

Character.AI может в любой момент изменить структуру сайта, API, HTML, CSS-классы или сетевые endpoints. Такие изменения могут временно или полностью нарушить работу отдельных функций userscript.

Скрипт распространяется в формате «как есть».

## Предупреждение

Используйте userscript на свой страх и риск.

Поскольку архив хранится локально в браузере, очистка данных сайта, хранилища браузера или `localStorage` может удалить локально сохранённые данные архива.

Если архив важен, рекомендуется периодически создавать JSON-резервную копию.
